# Earth Bar LLC website

Marketing site for Earth Bar LLC — herbal consultations with Dr. Catalina Cali in Martinez / Augusta, Georgia.

## Develop

```bash
cd earthbar-website
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Content and contact details reflect the public Earth Bar LLC brand (phone, studio address, consultation packages). The contact form is a client-side preview only until booking/email integration is connected.
